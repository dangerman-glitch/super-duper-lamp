Dangerman Training Systems Meta setup walkthrough 28 Aug 2026

Set up Meta yourself, in about an hour

I have no browser in this session, so I cannot click through this with you — but every field below is filled in with the values this plan actually needs. Work top to bottom with Chrome open. Step 2 is the one that takes days, so start it and let it run.

Read this before you click anything

The decision that is hard to undo Create all of this under a new Business Portfolio for Dangerman Training Systems — not your personal account, and not Myriad's. You have said you may break off on your own. If the pixel, the ad account and the audiences live under the gym's portfolio, you hand them back on the way out, along with every retargeting audience you spent money building. Starting a separate portfolio today costs you ten minutes. Migrating one later is painful and sometimes impossible.

One honest caveat about what follows: Meta renames things constantly. I have described each step by where you are going and what it must end up saying rather than promising an exact button label. If a label differs, the destination and the values are still right. If something genuinely does not match, tell me what you see and I will work it out with you.

The sequence

Seven steps, one of which is just waiting

01

Create the business portfolio

business.facebook.com → Business settings → Business portfolios → Create

If you already have one for the gym, create a second one anyway. Use your own email as the admin, not a shared gym address.

02

Start business verification — do this first, then walk away

Business settings → Security Center → Start verification

This is the long pole. Review can take a few days to two weeks and nothing downstream is fully unblocked until it clears. Meta wants documents proving the business is real: registration or formation paperwork, an EIN letter, a utility bill or bank statement showing the business name and address. The name on your documents must match the portfolio name exactly — a mismatch is the single most common rejection.

If you are a sole proprietor with no LLC Verification is harder without formation documents. You can often still get an ad account running for manual campaigns while unverified; it is the API access in step 7 that really needs it. If you hit a wall here, tell me and we will sequence around it rather than stall.
03

Connect the Instagram account and Facebook Page

Business settings → Accounts → Instagram accounts / Pages → Add

Add the Dangerman OWL Instagram and the associated Page to this portfolio. This is what later lets the system read saves, shares and profile visits — the numbers I have never been able to see — and what lets ads run as your brand rather than an anonymous advertiser.

Then add a payment method under Billing. Set an account spending limit of $150 while we are testing — a hard ceiling Meta will not cross even if something is misconfigured. Raise it later when the numbers justify it.

05

Create the pixel and put it on the quiz

Events Manager → Connect data sources → Web → Create

Name it Dangerman Remote. Meta will give you a base code snippet and a dataset ID. The snippet goes in the <head> of every page of the Find Your Phase quiz and the booking page.

How you install it depends on what the quiz is built on — if it is Typeform, Squarespace, Kajabi or similar there is usually a "tracking code" or "custom header" box that takes it directly. Tell me the platform and I will give you the exact placement.

06

Define the two events

Events Manager → your dataset → Custom conversions (or Aggregated Event Measurement)

Two events, wired separately, because they do different jobs. The first is what the optimiser steers on — it needs to fire often enough to train. The second is the actual scoreboard.

Event 1
quiz_completed — fires on the quiz results page
Purpose
Optimisation signal. This is what the campaign optimises for.
Event 2
call_booked — fires on the booking confirmation page
Purpose
Measurement only. Never set this as the optimisation event.

If the quiz can pass the result through, add the phase (learn, improve, compete) as a parameter on quiz_completed. That is what lets the routing send Improve and Compete to the call and Learn to nurture — and later it tells us which phase actually converts, which is worth knowing.

Verify before moving on. Install the Meta Pixel Helper Chrome extension, take the quiz yourself, and confirm both events fire green. A campaign optimising against an event that never fires will spend your money and teach us nothing.

07

Create the API app — the part that lets me automate it

developers.facebook.com/apps → Create app → Business → link it to the Dangerman portfolio

Everything to this point gets you a working manual ad account. This step is what lets the system read performance and launch approved winners without you in the Ads Manager UI.

Add the Marketing API product. Then, back in Business settings → Users → System users, create a system user with admin access to the ad account and generate a token with these scopes:

Scopes
ads_management, ads_read, business_management, instagram_basic, instagram_manage_insights, pages_read_engagement
Token type
System user token, never-expiring

When you are done

Four values to send me

  • Ad account ID — starts act_
  • Pixel / dataset ID — a long number from Events Manager
  • Business portfolio ID
  • Instagram account handle connected in step 3
Not the token Send the four IDs above in chat, but do not paste the system user token here. It is a permanent credential with spending authority over your ad account, and this conversation is stored. Put it in an environment variable or a secrets manager and tell me the variable name. If you have already pasted one anywhere, revoke it in Business settings and generate a new one.

With the four IDs I can finish Phase 02 — the collector and scorer — and hand you the first ranked table of every post you have published. That runs on data, not spend, so it happens while verification is still pending.

One thing to set now, while you are in there. When you build the first campaign, targeting must exclude the Indianapolis metro. You said the goal is outside Indianapolis, and Meta will happily serve your ads to people three miles from the gym who would have found you anyway. It is one field, and it is easy to forget.
